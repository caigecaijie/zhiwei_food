## 一、项目概述

### 1.1 项目背景

参考竞品「饿宝宝菜单」，打造一款集 **菜谱管理 + 智能配菜 + 社区分享 + 点餐协作** 于一体的微信小程序。

解决用户痛点：
- 小红书菜谱参差不齐，难以筛选优质做法
- 冰箱里有食材却不知道做什么
- 家庭/聚餐点餐时沟通成本高
- 想记录和分享自己的拿手菜，但缺少垂直社区

### 1.2 产品定位

**一句话定位**：你的私人厨房管家 + 厨艺社交圈

**核心价值**：
- 让每个人都能找到「今天吃什么」的答案
- 让好菜谱被看见、被复刻、被传承

### 1.3 目标用户

| 用户类型 | 特征 | 核心诉求 |
|---------|------|---------|
| 家庭主妇/煮夫 | 每天做饭，追求效率和营养 | 快速配菜、采购清单、营养均衡 |
| 厨艺爱好者 | 喜欢尝试新菜、分享作品 | 菜谱管理、社区互动、成就系统 |
| 合租/聚餐人群 | 多人协作点餐 | 邀请下单、AA分账、投票选菜 |
| 厨房小白 | 不会做饭，需要引导 | AI生成菜谱、步骤引导、难度分级 |

## 三、核心功能需求

### 3.1 菜谱管理模块（厨房）

#### 3.1.1 菜谱列表
- 按分类展示（荤菜/素菜/海鲜/汤羹/凉菜/主食/甜品）
- 支持搜索（菜名/食材/标签）
- 卡片展示：封面图、菜名、简介、标签、难度、用时
- 支持「我创建的」「我收藏的」筛选

#### 3.1.2 添加菜谱
- 基础信息：菜名、封面图、分类、难度、用时、份量
- 食材清单：食材名 + 用量（支持单位换算）
- 制作步骤：文字描述 + 步骤图/视频
- 小贴士：烹饪技巧、替代食材
- 标签：口味（清淡/酸辣/鲜香）、场景（早餐/便当/宴客）、人群（减脂/儿童/老人）

#### 3.1.3 菜谱管理
- 编辑/删除菜谱（仅创建者）
- 收藏/取消收藏
- 复制菜谱（基于别人的菜谱二次创作）
- 菜谱版本管理（同一道菜的不同做法版本）

#### 3.1.4 分类管理
- 自定义菜谱分类（如"我家的家常菜"、"周末宴客菜"）
- 拖拽排序
- 批量移动菜谱到分类

---

### 3.2 点餐协作模块

#### 3.2.1 购物车
- 从菜谱列表一键加入购物车
- 购物车显示：菜品、数量、备注（少辣/不要葱）
- 调整数量、移除菜品
- 购物车角标实时更新

#### 3.2.2 邀请下单
- 发起人创建「饭局」，生成邀请链接/小程序码
- 受邀人加入后可共同加菜
- 实时同步所有人的加菜操作
- 显示「谁点了什么」

#### 3.2.3 订单
- 订单列表：全部/待处理/已完成
- 订单详情：菜品清单、下单人、下单时间、备注
- 订单状态流转：待确认 → 制作中 → 已完成
- 支持按订单查看历史点过的菜

#### 3.2.4 AA分账（进阶）
- 按人头或按菜品分摊费用
- 生成结算明细
- 可导出/截图分享

---

### 3.3 厨神圈模块（社区）

#### 3.3.1 动态发布
- 分享菜谱 + 成品图/制作过程视频
- 关联菜谱（从已创建的菜谱中选择）
- 添加话题标签（#减脂餐# #一周早餐#）
- 设置可见范围（公开/仅关注/私密）

#### 3.3.2 动态展示
- 信息流（推荐/关注/最新）
- 卡片：封面图、作者、菜名、点赞/评论/收藏数
- 点击查看详情：步骤、食材、评论区

#### 3.3.3 互动
- 点赞、收藏、评论（支持回复）
- 转发到微信好友/群
- 关注作者

#### 3.3.4 复刻挑战
- 看到别人的菜谱，点击「我要复刻」
- 上传自己的成品图，与原图对比展示
- 复刻数计入菜谱热度

#### 3.3.5 排行榜
- 今日厨神榜（按点赞/复刻数）
- 热门菜谱榜
- 话题榜

---

### 3.4 智能配菜模块

#### 3.4.1 食材匹配菜谱
- 用户输入现有食材（支持多选）
- 系统匹配「能做这些菜」
- 按匹配度排序（用到的食材越多越靠前）
- 缺少的食材高亮提示，可一键加入采购清单

#### 3.4.2 AI 生成菜谱
- 输入：食材 + 口味偏好 + 人数 + 场景
- 大模型生成：菜名、食材清单、步骤、小贴士
- 生成结果可直接保存为菜谱
- 支持「重新生成」「换个做法」

#### 3.4.3 冰箱管理
- 录入冰箱食材（名称、数量、保质期）
- 临近过期食材红色提醒
- 优先推荐消耗快过期食材的菜谱
- 支持扫码快速录入（扫食材包装条码）

#### 3.4.4 营养分析
- 分析菜谱的营养成分（蛋白质/碳水/脂肪/热量）
- 一餐搭配的营养均衡度评分
- 减脂/增肌等目标的饮食建议

## 四、发散创意点（提升可玩性）

### 4.1 成长体系
- **厨龄系统**：累计做饭天数，解锁称号（见习厨师 → 料理铁人 → 厨神）
- **成就徽章**：
  - 🌱 初出茅庐：完成第一道菜
  - 🐟 海鲜新手：第一次做鱼
  - 🔥 连续7天做饭
  - 🌍 美食探索者：尝试10种不同菜系
- **难度挑战**：菜谱分 Lv1-Lv5，完成高难度菜获得更多经验

### 4.2 趣味玩法
- **每日一题**：「今天吃什么」转盘，解决选择困难
- **厨艺PK**：两人做同一道菜，社区投票谁更好
- **菜谱盲盒**：随机推荐一道没做过的菜
- **节气食单**：根据24节气推荐时令菜
- **天气菜单**：下雨天推荐煲汤、大热天推荐凉拌

### 4.3 实用工具
- **计时器**：菜谱步骤中可一键启动倒计时（蒸8分钟、炖1小时）
- **单位换算**：大勺/小勺/克/毫升一键换算
- **份量换算**：3人份 → 5人份自动调整食材量
- **采购清单**：根据菜谱自动生成买菜清单，可勾选已买
- **语音输入**：做饭时手忙，语音输入食材和步骤

### 4.4 社交增强
- **家庭菜单**：绑定家人，共享菜谱库
- **厨艺传承**：长辈录入拿手菜，晚辈复刻，形成家族菜谱
- **拼单买菜**：同小区用户拼单采购，降低成本
- **菜谱悬赏**：发布「想吃XX菜求做法」，社区用户提供方案

### 4.5 内容生态
- **原创认证**：菜谱作者可申请原创标识
- **优质菜谱精选**：编辑/算法推荐精品菜谱
- **菜谱版权保护**：搬运举报机制
- **话题活动**：官方发起 #一周不重样早餐# 等活动，奖励优质内容

## 五、非功能需求

### 5.1 性能
- 页面首屏加载 < 2s
- 列表滚动流畅（60fps）
- 图片懒加载，云存储 CDN 加速

### 5.2 兼容性
- 微信基础库 2.20.0+
- 兼容 iOS / Android
- 适配主流屏幕尺寸

### 5.3 安全
- 用户数据加密存储
- AI 接口密钥存云函数环境变量，不暴露前端
- 内容审核（文字/图片）防违规

### 5.4 可用性
- 离线可查看已缓存的菜谱
- 网络异常友好提示

## 六、技术架构

### 6.1 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 微信原生小程序 + TypeScript | 现有项目基础 |
| 后端 | 微信云开发 | 云函数 + 云数据库 + 云存储 |
| UI 组件 | TDesign Miniprogram | 腾讯官方组件库，风格统一 |
| AI | 豆包/通义千问 API | 云函数调用，密钥不外泄 |
| 内容审核 | 微信内容安全 API | 云函数调用 msgSecCheck |

### 6.2 云数据库集合设计

```
users          // 用户表（openid、昵称、头像、厨龄、称号）
recipes        // 菜谱表（标题、分类、食材、步骤、作者、标签、点赞数）
recipe_versions// 菜谱版本表（同一道菜的不同做法）
carts          // 购物车表（用户、菜品、数量、备注）
orders         // 订单表（订单号、菜品清单、状态、创建人、参与人）
dinner_parties // 饭局表（发起人、参与人、状态、邀请码）
posts          // 动态表（内容、图片、关联菜谱、话题、点赞数）
comments       // 评论表（动态ID、用户、内容、回复）
fridge_items   // 冰箱食材表（用户、食材、数量、保质期）
achievements   // 成就表（用户、成就ID、解锁时间）
```

### 6.3 云函数清单

| 云函数 | 功能 |
|--------|------|
| recipeCRUD | 菜谱增删改查 |
| aiGenerateRecipe | 调用大模型生成菜谱 |
| matchRecipeByIngredient | 根据食材匹配菜谱 |
| contentModeration | 内容安全审核 |
| orderManage | 订单管理 |
| socialInteract | 点赞/评论/关注 |

## 七、分阶段实施计划

### 第一阶段：MVP（菜谱工具 + 点餐协作）
- 菜谱增删改查
- 分类管理
- 食材匹配菜谱
- 购物车 + 下单
- 邀请下单 / 饭局（多人协作加菜）

- AI 生成菜谱
- 厨神圈（发布/点赞/评论）
- 收藏系统
- 用户信息完善

### 第三阶段：成长体系
- 复刻挑战
- 成就系统 / 厨龄
- 冰箱管理

- 营养分析
- AA分账
- 节气/天气推荐
